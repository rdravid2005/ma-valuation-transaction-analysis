# M&A Valuation & Transaction Analysis

## Hypothetical Rockwell Automation Acquisition of Cognex

This repository contains an independent, hypothetical analysis of a potential acquisition of Cognex Corporation (NASDAQ: CGNX) by Rockwell Automation, Inc. (NYSE: ROK). The project is designed to demonstrate public-company research, operating-model construction, valuation, purchase-price and financing analysis, accretion/dilution, synergy analysis, and transaction presentation skills.

> **Status:** In development. Transaction selection, research, model architecture, five-year historical analysis, and the guidance-anchored operating forecast are complete. Standalone valuation is next.

## Preliminary thesis

Cognex could add a differentiated machine-vision and visual-data layer to Rockwell's industrial automation platform. The project will test whether potential commercial and operating benefits could justify an acquisition premium without creating unacceptable dilution, leverage, or integration risk.
